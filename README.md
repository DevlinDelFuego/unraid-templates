# Unraid Templates — DevlinDelFuego

Community Applications templates and plugins for Unraid, focused on hardware monitoring and self-hosted tools.

## Plugins

| Plugin | Description |
| --- | --- |
| [LSIUtil](Unraid%20LSIUtil/) | HBA temperature and health monitor for LSI SAS controllers (9207-8i / SAS2308 family) |

## Templates

| Template | Description |
| --- | --- |
| [Easy-Uploader](Easy-Uploader/) | Simple file uploader |
| [actual-ics](actual-ics/) | ICS calendar sync for Actual Budget |
| [domain-watchdog](domain-watchdog/) | Domain expiry monitoring |
| [monetr](monetr/) | Personal finance and budgeting |
| [yourls](yourls/) | Self-hosted URL shortener |

## Installation

Install any plugin directly from the Unraid Community Applications browser, or paste the plugin URL into **Plugins > Install Plugin**:

```
https://raw.githubusercontent.com/DevlinDelFuego/Unraid-LSIUtil/main/lsiutil.plg
```
